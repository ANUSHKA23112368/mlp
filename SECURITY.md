# Security Policy

## Supported Versions

The following versions of CivicShield AI currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

We take the security of CivicShield AI seriously. If you discover a potential vulnerability, please report it responsibly:

1. **Do not disclose publicly**: Please refrain from creating public GitHub issues for security vulnerabilities.
2. **Submit details**: Email the security report with:
   - Type of vulnerability
   - Steps to reproduce or proof-of-concept
   - Impact assessment
3. **Response time**: You will receive an initial response acknowledging the vulnerability report within 48 hours.
4. **Remediation**: Verified vulnerabilities will be patched promptly with an advisory released alongside the patch.
